## The Magic Number: 14.4mm

This is the spacing between the 3π+'s 5 line sensors.

```
Sensors:     [0] [1] [2] [3] [4]
             ├──┤ ├──┤ ├──┤ ├──┤
Spacing:     14.4mm × 4 = 57.6mm total coverage

When a black cross is centered:
  Sensors 1,2,3 see black
  Position offset = 0
  ✓ Robot is perfectly aligned
```

## How It Works in 3 Steps

### Step 1️⃣: Detect
```
Line Sensor Reading
├─ Sensor 0: 750 (white)
├─ Sensor 1: 200 (black) ✓
├─ Sensor 2: 150 (black) ✓
├─ Sensor 3: 180 (black) ✓
└─ Sensor 4: 800 (white)

Result: Cross detected!
```

### Step 2️⃣: Measure
```
Center of detected black = (1+2+3)/3 = 2.0
Ideal center position = 2.0
Offset = (2.0 - 2.0) × 14.4mm = 0mm
Result: Robot is centered ✓
```

### Step 3️⃣: Correct
```
If within 10cm of target:
  Position = Target Position
  Drift = Cleared
  Ready for next waypoint
```

## Key Changes to circle_touch.py

### Before
```python
# Navigation only
while True:
    read encoders and gyro
    calculate position
    navigate to target
    # Drift accumulates over time ❌
```

### After
```python
# Navigation + Cross Detection + Correction
while True:
    read encoders and gyro
    calculate position
    detect black cross
    if cross and near target:
        reset position to target  # Drift cleared ✓
    navigate to next target
```

   ├─ Detects the 2-inch reference arm extending from cross

   ├─ Robot detects cross at home on startup
   ├─ Sets heading = 0° using extended X-axis line
   ├─ All subsequent headings are calibrated relative to this
   └─ initial_heading_calibrated flag prevents re-calibration

✓ 3. HEADING ALIGNMENT AT TARGETS
   ├─ New state_align_heading (state 5)
   ├─ estimate_heading_error_from_cross() estimates error
   ├─ Slowly turns until heading aligned (< 6° error)
   ├─ correct_heading_at_target() applies correction gradually
   └─ Ensures position correction happens when aligned

✓ 4. SPIRAL SEARCH PATTERN
   ├─ New state_spiral (state 4)
   ├─ Triggered when near waypoint but cross not found
   ├─ Expands outward while continuously turning
   ├─ Covers ~3m radius in 15 seconds
   ├─ Exits if cross found or timeout
   └─ Finds targets even with significant dead-reckoning drift
